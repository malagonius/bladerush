# 4. Core Gameplay Loop

## Proposed Loop
1. Start a run.
2. Enter a combat encounter.
3. Defeat the enemy or fail.
4. Receive the encounter reward.
5. Choose the next route/path, event, upgrade, or other available opportunity.
6. Enter the next encounter.
7. Face elites, events, and bosses.
8. End the run through death or victory.
9. Convert eligible rewards into persistent progression.
10. Start another run with new options.

## Encounter Rewards
After winning an encounter, the player receives **3 defensive-card choices** and chooses **1**.

The chosen card is added to the hidden defensive deck for the current run.

This is a settled rule, not a TBD reward-count decision.

- **Events:** can manipulate deck strength and other run state.
- **Encounter rewards:** primarily build the defensive deck by adding one chosen card from three options.
- **Training:** removes one non-Nothing defensive card and enables deck specialization.
