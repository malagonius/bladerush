# 9. Enemy Design

## Design Rule
Each enemy archetype must introduce a distinct combat problem, not merely a different health value or visual model.

## Initial Archetype Candidates
- Basic attacker.
- Fast attacker.
- Heavy attacker.
- Defensive enemy.
- Ranged or zoning enemy.
- Counter/parry enemy.
- Elite variant.
- Boss.

## Reusability Goals
- Variants should reuse rigs and animation sets where possible.
- Difficulty can come from timing, patterns, modifiers, and combinations.
- Enemy readability must remain strong on mobile screens.
