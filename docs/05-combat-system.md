# 5. Combat System

## Core Intent
Combat should be readable, timing-focused, and primarily centered on a small number of meaningful defensive/offensive decisions.

## Candidate Player Actions
- Basic attack.
- Directional attack.
- Block.
- Parry.
- Dodge or evade.
- Heavy/special attack.
- Run-specific abilities.

All items above are candidates, not confirmed features.

## Candidate Encounter Model
- Primarily 1v1 encounters.
- Enemy presents readable attack telegraphs.
- Player reacts using attack/defense timing.
- Successful actions create damage, stagger, counterattack, or positional advantage.

## Core TBD Questions
- Real-time vs pause/slow-time combat.
- Exact input model: buttons, swipes, directional gestures, or hybrid.
- Whether the player controls movement freely.
- Number of simultaneous enemies.
- Direction system and attack lanes.
- Stamina/energy/resource model.
- Health, armor, wounds, and healing rules.
- Parry timing window and failure consequences.
- Whether dodge exists alongside block/parry.
- Whether attacks can be chained.
- Whether enemy attacks can be interrupted.
