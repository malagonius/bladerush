# 8. Build and Upgrade System

## Purpose
Build choices should alter the player's preferred combat behavior and create recognizable synergies.

## Candidate Upgrade Families
- Weapon modifications.
- Attack modifiers.
- Defensive/parry modifiers.
- Dodge/ mobility modifiers.
- Status effects.
- Passive relics.
- Risk/reward effects.
- Resource economy modifiers.

## Example Build Directions
- Fast attacks + bleed.
- Heavy attacks + stagger.
- Perfect parries + counter damage.
- Defensive play + retaliation.
- Dodge-focused mobility + back attacks.
